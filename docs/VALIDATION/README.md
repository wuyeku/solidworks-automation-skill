# Validation Evidence

本目录只保存可公开、可检索的验收摘要和脱敏机器证据。原始 SolidWorks 模型、BMP、PDF、DXF、DWG 与大型输出保存在：

`<LOCAL_VALIDATION_ROOT>\validation`

## 证据等级

| 等级 | 含义 |
|---|---|
| `source` | 源码存在 |
| `registered` | MCP 可发现和描述 |
| `offline_pass` | 离线测试通过 |
| `live_pass` | SolidWorks 2025 真机执行并回读成功 |
| `delivery_pass` | 文件保存、重开、导出和质量检查均通过 |
| `review_required` | 已达到部分证据，仍需人工或专项复核 |
| `blocked` | 缺少必要证据或存在确定错误 |
