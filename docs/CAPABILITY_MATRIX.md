## 五阶段成果

### 第一阶段

新增 24 个工具并升级孔特征和导出入口。零件、装配、工程图、BOM、钣金、焊件、检查和交付链路完成首次整链验证。

### 第二阶段

镜像特征、批量导出、剖视图和局部放大完成源码修复和定向真机验证。

### 第三阶段

工程图重复尺寸去重、标题栏关联、四视图、原生 BOM 和 PDF 导出完成修复与验证。

### 第四阶段

Ø20 外圆和 Ø8 内孔自动直径标注通过。原生 BOM 自动气泡与 BOM 项目号对齐。

### 第五阶段

零件和装配体属性卡、文件级和配置特定属性、工程图 `$PRPSHEET` 标题栏、原生 BOM 和 Excel BOM 完成属性数据链验证。

### 工程图模板修复专项

- SolidWorks 2025 图幅枚举已校正为 A4=6、A4P=7、A3=8、A2=9、A1=10、A0=11，自定义格式为 12。
- 默认模板、指定图幅标准模板和显式模板均通过实际尺寸验证。模板不匹配会在创建工程图前阻断。
- 标题栏已有属性链接按语义读取并跳过重复写入。只有显式手动覆盖才允许额外插入。
- 图纸格式切换使用 `RemoveModifiedNotes=True`，并验证实际模板、图幅、方向和用户注释未丢失。
- 同源 A3 工程图的手动 SolidWorks DXF 与 MCP DXF 在 147 个实体、57 个文字对象、文字坐标、字体、字高、图层、图框和标题栏上一致。
- PDF 为有效单页 A3 横向文件，57 个可提取文字片段使用 `HYSWLongFangSong`。
- DWG 可被 AutoCAD 2025 只读打开，147 个实体与 MCP DXF 在 `1e-7 mm` 容差内一致，最大数值偏差为 `4.860112312599085e-11 mm`。
- 当前 Codex GUI 仍连接修复前启动的旧 MCP。最新源码已经由隔离 MCP 进程验证，GUI 正式重连尚未执行。

## 尚未解决

- 属性卡必填项只显示星号，空值阻断机制未验证。
- 多配置 BOM 的分组和合并规则未专项验收。
- 工程图模板文字仍可能产生碰撞提示。模板内原生重复字段已与程序重复字段区分。
- `property_tab_template` 应使用绝对路径。
- Edge Flange 尚未开发。
- 93 个工具尚未全部完成 SW2025 真机逐项闭环。
- 复杂工程图的原始 Pack 副本首次打开会进入 dirty 状态。执行一次原生保存并重新打开后，正常和只读状态均可保持 clean，后续导出通过。
- S2.7.1 旧复杂工程图 DXF 有 71 个 MTEXT 存在仅 Y 方向、最大 `0.088818 mm` 的位置变化。该历史记录保留，新的干净 A3 同源 DXF 对照已通过。
- 2026-11-19 的历史 DXF/DWG `SaveAs` 错误码 1 在当前清洗后的复杂工程图样件上未复现，唯一根因仍未确认。
- 当前 Codex GUI 尚未加载修复后的 MCP 进程，需要在不影响其他 Codex 会话的情况下另行安排正式重连。
- 本轮 A3 零件图不包含 BOM，装配图 BOM 的 PDF/DWG 最小回归未包含在本轮范围。

## 证据口径

- `registered` 表示工具存在并可通过发现入口找到。
- `schema` 表示真实输入 Schema 可读取。
- `offline_pass` 表示 pytest 或契约测试通过。
- `live_pass` 表示 SolidWorks 2025 真机调用和回读通过。
- `delivery_pass` 表示最终文件可保存、重开、打开或解析，并通过质量检查。
